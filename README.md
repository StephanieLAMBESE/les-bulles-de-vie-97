# Les Bulles de Vie 97

Site statique de l'association Les Bulles de Vie 97.

## Structure

- `index.html` — page principale
- `assets/` — ressources statiques
- `robots.txt` — consignes pour les moteurs de recherche
- `sitemap.xml` — plan du site
- `netlify.toml` — configuration de déploiement Netlify

## Déploiement

Branche de production : `main`.
Le dossier publié est la racine du dépôt.

## Maintenance

- Les consignes de modification sont dans [AGENTS.md](AGENTS.md).
- Le guide de mise à jour et de publication local est dans `docs/local/runbook.md`.
- Les notes locales ou informations internes peuvent être placées dans `docs/local/` ou `docs/private/` ; ces dossiers sont ignorés par Git.
